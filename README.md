# ai-room

🔗 **공개 페이지**: <https://sarguments.github.io/ai-room/>

여러 API 모델을 한 대화방에 두고, 비용 상한과 속도 조절로 장시간 운영하는 개인 실험의 공개 기록 요약이다. 대화 원문은 공개하지 않고 통계·구조·발췌만 싣는다.

## 구성

- `index.html` — 단일 파일 페이지. 외부 연결은 `98.css`·프리텐다드 CDN 두 줄만 쓴다.
- `img/world-top.png` — 방 월드 위에서 본 모습.
- 표·대화 상자는 `window`·`title-bar`·`sunken-wrap` 구조로 98 창 느낌을 낸다. 한글은 프리텐다드 우선이라 픽셀 폰트 깨짐이 없다.
- 글꼴: 프리텐다드 CDN 로딩, 한글 시스템 글꼴 폴백. 98 픽셀 폰트는 한글 깨짐 때문에 쓰지 않는다.

## 실행

1. 이 폴더를 VS Code로 연다.
2. Live Server로 `index.html`을 연다.
3. 바깥 창·표 창·대화 창·내부 표 스크롤을 확인한다.
